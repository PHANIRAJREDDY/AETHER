## Status

# Purpose

The Desktop Engine is responsible for the entire desktop user interface of AETHER.

It provides the application shell that hosts every engine inside the platform.

---

# Responsibilities

- Main Window
- Sidebar
- Toolbar
- Status Bar
- Workspace
- Dock Manager
- Theme Manager
- Window Manager
- Notifications
- Command Palette
