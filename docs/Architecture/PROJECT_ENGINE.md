# Purpose

The Project Engine manages every project created inside AETHER.

It provides project creation, storage, organization, metadata management, and lifecycle control.

---

# Responsibilities

- Project Creation
- Project Opening
- Project Saving
- Project Metadata
- Project Templates
- Project Import
- Project Export
- Project Search
- Project Archive
